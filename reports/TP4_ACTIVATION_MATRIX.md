# TP4 Activation Matrix

- no_capability_activated: `True`

## local_answer_and_self_description

- classification: `Production Ready`
- rationale: Deterministic local answers and current-state self-description have been repeatedly validated.
- remaining_risks: natural language coverage is still curated

## read_only_evaluation_regression_loop

- classification: `Production Ready`
- rationale: OV4 activated this as a read-only trial and OV5 composed it safely.
- remaining_risks: operator interpretation may over-trust fixture scores

## fixture_only_noncanonical_ingestion

- classification: `Pilot Ready`
- rationale: OV6 and RC1 wave chain validated allowlisted fixture ingestion into noncanonical records.
- remaining_risks: real operator documents can be messier than fixtures

## operator_reviewed_noncanonical_semantic_consolidation

- classification: `Pilot Ready`
- rationale: TP0-TP3 showed reversible noncanonical consolidation can improve reasoning under governance.
- remaining_risks: persistent pilot has not yet run on real operator sessions

## read_only_substrate_retrieval_and_grounded_synthesis

- classification: `Pilot Ready`
- rationale: OV1-OV5 validated grounded fixture answers from noncanonical substrate records.
- remaining_risks: real-world recall quality still untested

## simulated_approval_review_integration_state_machine

- classification: `Experimental`
- rationale: State machine exists and is tested, but live integration remains disabled.
- remaining_risks: approval semantics must remain strict under UI usage

## rollback_execution

- classification: `Experimental`
- rationale: Rollback plans and drills are stable, but execution remains simulated or workspace-delete only.
- remaining_risks: automatic rollback execution has not been enabled

## provider_assisted_evidence

- classification: `Blocked`
- rationale: Provider evidence pathways exist as gated designs, but provider calls are prohibited for TP4.
- remaining_risks: provider output could be mistaken for authority, cost/secret exposure

## canonical_memory_writes

- classification: `Blocked`
- rationale: Canonical mutation remains outside TP4's boundary.
- remaining_risks: irreversible belief pollution

## model_training_or_finetuning

- classification: `Blocked`
- rationale: TP0-TP3 are substrate-learning pilots, not model-weight training.
- remaining_risks: weight changes would confound substrate evidence

## autonomous_action_execution

- classification: `Blocked`
- rationale: Action/execution scaffolds exist but no autonomous action is safe or required for this pilot.
- remaining_risks: side effects, authorization ambiguity

## hyb1_runtime_variant

- classification: `Research Only`
- rationale: HYB1 remains dormant/env-gated and is not needed for persistent-pilot design.
- remaining_risks: promotion could change baseline during pilot
