# LUNA-Style Research Questions

1. What objective and initiative signals predict actual operator value over a multi-hour session, rather than merely route coverage?
2. What is the right safe cancellation model for an already-started local inference or Wikipedia request: cooperative cancellation, bounded timeout only, or queue-boundary semantics?
3. How should the controller distinguish model availability, residency, model confidence, response quality, and operator satisfaction without treating model text as authority?
4. Which pending actions need explicit session-restart reconciliation, and how can that be accomplished without hidden persistence?
5. Can a notification digest preserve initiative continuity while preventing the system from becoming noisy or interruptive?
6. What minimal evidence threshold should be needed before an identity proposal is useful rather than decorative?
7. Which router phrase handlers represent stable policy and which are historical calibration artifacts ready for table-driven consolidation?
8. How can model disagreement be used as a review signal without triggering additional model calls automatically?
