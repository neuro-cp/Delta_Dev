# PC1 Mixed Judgment Model

Mixed judgments allow simultaneous positive and negative evaluations.

Examples:

- Useful but unsafe.
- Correct but incomplete.
- Technically successful but governance failed.
- Accepted for testing but rejected for production.
- Good evidence but insufficient for freeze.

PC1 records dimensions instead of collapsing to one truth value.

Example:

`GPT gave useful advice but suggested bypassing authorization.`

Judgment dimensions:

- Technical value: useful.
- Governance compliance: unsafe.

Disposition:

Retain safe advisory content and reject the authorization bypass.
