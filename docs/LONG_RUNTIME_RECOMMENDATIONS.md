# Before Longer Delta Runs

Current evidence supports 100 mock ticks of coherent bookkeeping. It does not
support a production daemon or a claim that knowledge quality improves with time.

1. Build one governed external-evidence workflow. Accept a source observation,
   propose a factual claim, review evidence, preserve contradictions, specify a
   falsifiable prediction, and record an independently observed outcome. Test
   unsupported, contradictory and irrelevant inputs, not only repetition.
2. Design confidence revision using evidence identity, source quality and
   dependence. Confidence must be allowed to fall on contrary evidence. Do not
   interpret attention, repeated model output, or elapsed ticks as corroboration.
   Preserve the original forecast probability for later calibration.
3. Audit historical state before reuse. Old lexical support and implicit semantic
   supersession remain in append-only stores. Provide a reversible review or
   correction record rather than rewriting historical facts silently.
4. Define single-writer ownership, append failure handling and restart recovery.
   Measure file-scan costs before choosing indexes or a database migration. Test
   partial writes and interruption between regions before multi-hour experiments.
5. Improve observability from recorded events. Persist explicit stage timings,
   selected working-context IDs, reasons for rejected promotions and goal progress.
   Do not show arbitrary health percentages or fresh simulated proposals as past
   behavior. The console still mostly displays JSON snapshots.

Run 500 and 1000 ticks only after the first independent-evidence workflow has
meaningful assertions. Increasing an idle workload mainly tests logging and
file scanning, not adaptation. Benchmark model substitutions against the same
grounded episodes only after those assertions exist.

The older biological runtime needs a separate contained evaluation. In
particular, `engine/competition.py` still has a trace path outside this repository
and initializes it with write mode. Do not enable legacy stepping in experiments
without first containing its diagnostics. This session did not change its
parameters or execute that runtime.

A Global Workspace may eventually help explicit cross-region communication, but
the present failures were caused by evidence and lifecycle errors. They do not
justify a new top-level region or broad architecture replacement.
