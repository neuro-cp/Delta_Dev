# Runtime ARC VIII Specialist Deliberation

ARC VIII introduces advisory cognitive specialists.

Specialists are not autonomous agents. They provide perspective-specific
reasoning, support, limitations, and bounded confidence.

Default profiles:

- Evidence Specialist
- Logic Specialist
- Planning Specialist
- Risk Specialist
- Scientific Specialist
- Historical Specialist
- Systems Specialist
- Contradiction Specialist
- Procedural Specialist
- Meta-Reasoning Specialist

Specialists never execute, mutate memory, mutate knowledge, bypass governance,
or become authoritative. The executive layer selects specialists, and the
kernel coordinates their transient deliberation.
