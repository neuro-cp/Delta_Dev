# PC1 Response Planning

PC1 response planning asks what answer form would actually help the operator.

Supported response shapes include:

- Decision.
- Checklist.
- Comparison.
- Narrative explanation.
- Recommendation.
- Freeze assessment.
- Pilot summary.
- Implementation proposal.
- Clarifying question.
- Evidence-standard explanation.
- Governance decision guidance.

The response shape is selected before answer generation in shadow mode. PC1 can later review whether a candidate answer matched the practical goal.
