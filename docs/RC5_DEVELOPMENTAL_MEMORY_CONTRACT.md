# RC5 Developmental Memory Contract

Developmental lessons are not automatic memory writes.

RC5 may produce a `DevelopmentalLesson` after comparative evaluation. The lesson contains an evidence-backed statement, scope, review status, and retention decision. It remains noncanonical and review-required until the operator accepts it through a governed workflow.

No RC5 benchmark or UI panel is allowed to write developmental memory autonomously. This preserves reversibility and prevents the system from silently teaching itself from unreviewed outcomes.
