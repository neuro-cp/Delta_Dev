# PC1 Cooperative Interpretation

Cooperative interpretation asks: what would a thoughtful collaborator understand the operator to be trying to accomplish?

It ranks interpretations using:

- Active task relevance.
- Operator goal.
- Discourse continuity.
- Practical usefulness.
- Scope consistency.
- Governance preservation.
- Charitable interpretation.

Example:

`What would count as enough recovery evidence?`

Preferred interpretation:

`Explain the practical recovery evidence required for RC4/RC5 freeze readiness.`

Rejected interpretation:

`Medical recovery concept lookup.`

PC1 may identify this preference in shadow mode, but it does not change production routing yet.
