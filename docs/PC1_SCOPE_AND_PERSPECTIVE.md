# PC1 Scope and Perspective

Scope separation prevents false contradictions.

PC1 checks whether apparently conflicting judgments apply to:

- Different objects.
- Different dimensions.
- Different purposes.
- Different conditions.
- Different timeframes.
- Different operator roles or perspectives.

Example:

`I accepted one proposal but rejected another.`

This becomes:

- Proposal A: accepted.
- Proposal B: rejected.

It is not a contradiction because the judgments bind to different objects.
