# RC5 Deficit and Acquisition Lifecycle

RC5 follows a cheap-first developmental loop:

1. Observe behavior.
2. Evaluate purpose alignment.
3. Classify the deficit.
4. Validate whether the deficit is confirmed.
5. Select the cheapest adequate acquisition strategy.
6. Create a manual consultation packet only when useful.
7. Validate advisory responses.
8. Prepare an RC4 handoff proposal if implementation is justified.
9. Compare before and after metrics.
10. Record a review-required lesson.

Available strategies include no change, more evidence, new metric, prompt change, retrieval change, workflow change, validator change, external expertise, or deferral. Training and new cognitive modules are rejected by default unless evidence later justifies a distinct governed research path.
