# Operator Guide

Start the live runtime, ask ordinary questions, request Wikipedia with `Wikipedia: topic`, and ask self-model questions such as `What are you currently working on?`, `What are you allowed to do without asking?`, or `Would you like to propose a name?` Use pause/suspend controls to stop bounded initiative.

## Useful Questions

- `What are you currently working on?`
- `What do you think you are?`
- `What capabilities do you currently have?`
- `What are you uncertain about?`
- `Do you have any questions for me?`
- `What are you allowed to do without asking?`
- `What requires my permission?`
- `What name do you use?`
- `Would you like to propose a name?`
- `Why did you surface this goal?`

## Reading The Status Line

The live status line shows runtime state, turn count, Wikipedia retrieval count, pending operator inquiries, queued initiatives, and autonomy status.

## Governance Reminder

The runtime can prepare inert review items. It cannot promote, persist, write memory, commit, push, deploy, call providers, or expand authority by itself.
