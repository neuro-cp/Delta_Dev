# Operational Self Model

The self-model is operational, not subjective. It records DELTA's identifier, identity status, capabilities, restrictions, objectives, unresolved questions, evidence sources, initiatives, resource limits, and health state.

## Fields

The model includes the system identifier, conversational identity, identity status, purpose statement, governance version, runtime version, current runtime state, current and disabled capabilities, restricted capabilities, active permissions, prohibited actions, objectives, queued objectives, unresolved questions, pending operator inquiries, evidence sources, recent developmental observations, limitations, uncertainty, resource limits, external surfaces, live status, sandbox status, last evaluation result, and health.

## Runtime Grounding

The model is rebuilt from live session state. For example, after a Wikipedia lookup it can report the active promotion-review objective and pending operator inquiry. If no identity evidence exists, the conversational identity remains `undefined`.

## Limits

The self-model is not a claim of consciousness. It may become stale if future capabilities are added without updating the wrapper, and it is session-scoped unless explicitly exported or promoted through governance.
