# Interactive Cognition Future Governance Contracts

## Personality Profile

Canonical owner: a dedicated versioned operator-profile record, separate from
the semantic graph, attention workspace, and SelfModelSnapshot. A profile may
affect presentation and timing only. It cannot grant authority, create goals,
admit memory, alter factual state, or represent emotion/consciousness.

Each profile version must retain operator approval, lineage, rollback target,
and a bounded change proposal. General users cannot edit administrative traits.

## External Outreach

This is a future single-send capability, not a background behavior. Eligibility
requires an objective milestone, public-recipient discovery, relevance dossier,
sealed draft, exact operator and recipient approval, attachment review, one send,
and an immutable send audit. No autonomous follow-up is permitted.

## Behavioral Adapter

Future training remains offline and governed: reviewed non-sensitive examples,
immutable cohort manifest, held-out evaluation, regression comparison, explicit
operator approval, versioned deployment, and rollback. Claims, authority,
consent, credentials, transient runtime state, changing preferences, and
unreviewed provisional content remain outside adapter weights.
