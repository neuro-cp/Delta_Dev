# RC5 Operator Pilot and Freeze Protocol

RC5 developer rehearsals can verify architecture, reports, safety flags, and UI panels. They do not count as real operator-pilot evidence.

Freeze requires real operator evidence showing that RC5 is useful, understandable, recoverable, and practical under actual use. Until that evidence exists, the correct freeze state is:

`RC5_FREEZE_PENDING_REAL_OPERATOR_PILOT`

Freeze review must verify:

- purpose remains operator-owned
- deficit detection is evidence-based
- acquisition avoids unnecessary architecture expansion
- external consultation remains manual/advisory
- RC4 handoff is required for implementation
- developmental memory is not written automatically
- reports distinguish fixtures from real sessions
- no provider/API calls occur
- no protected repository interaction occurs
