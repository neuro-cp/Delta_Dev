# Runtime ARC VI Executive Dashboard

ARC VI generates a static executive dashboard at:

`ui/delta_arc_vi_executive_dashboard.html`

The dashboard displays:

- executive goal
- planned tasks
- blockers
- transient decision graph
- resource estimates
- review state

The dashboard is static HTML. It performs no provider calls, no tool calls, no
actions, no memory writes, no scheduler activation, and no hidden state
changes.
