# DELTA ARC II Knowledge Object Reference

Object types:

- Entity
- Concept
- Observation
- Evidence
- Source
- Relationship
- Event
- Claim
- Hypothesis
- Procedure
- Rule

Required fields:

- `id`
- `type`
- `created`
- `updated`
- `provenance`
- `confidence`
- `review_state`
- `rollback_token`
- `audit_id`

No object is authoritative by default.
