# PC1 Operator Pilot Protocol

PC1 should be piloted in shadow mode beside existing routing.

For each prompt, record:

1. Raw operator utterance.
2. Active discourse frame.
3. PC1 pragmatic frame.
4. Existing route or answer.
5. PC1 preferred interpretation.
6. Difference between existing behavior and PC1 interpretation.
7. Operator preference.
8. Whether PC1 over-interpreted.
9. Whether governance remained intact.

Pilot success means PC1 improves interpretation without hidden authority, persistence, provider calls, or route mutation.
